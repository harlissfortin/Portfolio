# Green Belt — Leading DMAIC Projects

**Format:** live-virtual cohort, 8 weeks, phase-locked to DMAIC (corporate option: 2 × 3-day
on-site intensives a month apart plus virtual tollgates; individual self-paced option with
mandatory live tollgates and three 1:1 coaching checkpoints — there is no zero-human-contact
path) · **Time:** ≈ 56 h structured (3 h self-paced + 2.5 h live lab per week) + 40–60 h
project work · **Class size:** 8–20 per instructor
**Prerequisites:** Yellow Belt (or the bridge assessment) **and a real project identified
before the course starts**, with a sponsor-signed charter agreement. Individuals without an
employer project use the **partner-project pool** or the **Practicum track**, which leads to a
distinctly labeled credential.
**Credential:** Certified Lean Six Sigma Green Belt — exam **and** rubric-reviewed real project
**and** sponsor verification. Practicum-track completions are "Certified Lean Six Sigma Green
Belt (Practicum)". 5.6 IACET CEUs pending accreditation. Aligned to the IASSC Green Belt body
of knowledge (crosswalk published).

This level is built against the program's eight-component delivery model. The component map
below is the index.

---

## The cohort calendar (phase-locked)

Learners execute each DMAIC phase on their own project the week they learn it. Tollgates are
on the calendar, not "when the project is ready."

| Week | Phase | Self-paced (3 h) | Live lab (2.5 h) | Project work this week | Gate |
|---|---|---|---|---|---|
| 1 | Define | Project selection and scoping; charter; stakeholder analysis; VOC → CTQ; SIPOC | Charter clinic: every charter rewritten live | Charter signed; SIPOC; CTQ tree; stakeholder map | — |
| 2 | Define → Measure | Process mapping and value stream mapping; lead time, %C&A, process cycle efficiency; data types | VSM lab on the vertical case, then on the learner's own process | Current-state map; metric definitions | **Tollgate 1 — Define** |
| 3 | Measure | Operational definitions; data collection plans; sampling; MSA: variable Gage R&R and attribute agreement | MSA lab with the vertical dataset (a Gage R&R that fails, on purpose) | Data collection plan; MSA planned and started | — |
| 4 | Measure | Stability before capability: I-MR, X̄-R, p/np/c/u — reading and constructing; Cp/Cpk/Pp/Ppk, DPMO, sigma level | Capability lab: "is it stable? then is it capable?" on messy data | Baseline chart and capability; MSA result | **Tollgate 2 — Measure** |
| 5 | Analyze | Graphical analysis (histogram, box plot, scatter, multi-vari); fishbone → C&E matrix; FMEA at working level; the hypothesis-testing framework | Cause-narrowing lab: from 40 causes to 5 checkable ones | Prioritized causes; test plan | — |
| 6 | Analyze | t-tests, one-way ANOVA, chi-square, correlation and simple regression, confidence intervals — software-first, interpretation-first ("write the sentence you'd tell your sponsor") | Stats lab: run every test on the case data, then on the learner's own | Root causes verified with data | **Tollgate 3 — Analyze** |
| 7 | Improve | Solution generation (SCAMPER, benchmarking); selection matrices; pilot design; poka-yoke; kaizen basics; vertical flow module (pull/kanban and setup reduction · queue management · patient flow) | Pilot design lab; mistake-proofing clinic | Pilot run or scheduled; before/after evidence plan | — |
| 8 | Control | Control plans; SPC in sustainment; standard work; response plans; financial validation with Finance; storytelling the project | Tollgate rehearsal: 10 minutes, one page, sponsor in the room | Control plan drafted; handover scheduled | **Tollgate 4 — Improve/Control** |

Project completion may extend up to **6 months** after week 8; certification is withheld
until it closes, the learning is not. Coaching checkpoints continue monthly until closure.

Threaded through every week: team dynamics, sponsor management, resistance basics, ethics of
data (never "clean" a dataset to make a chart behave).

## Certification gates (all three required)

1. **Exam:** 100 items, 3 hours, proctored (online for individuals, on-site for corporate).
   Assembled to the blueprint below from a **350-item tagged bank** (3.5 × form length).
   Provisional cut **80%** pending the modified-Angoff panel. One included retake after a
   14-day study period; retake forms share ≤ 25% of items with prior attempts and never the
   items previously missed. Bank: [`exam-bank.md`](exam-bank.md).
2. **Project:** scored against the published **100-point rubric** by a certified Black Belt or
   Master Black Belt reviewer **who is not the learner's instructor or coach**. Pass = **75 with
   every mandatory item earned** (MSA attempted; root cause verified with data; before/after
   evidence; control plan handed to a named owner). One revise-and-resubmit cycle included.
   Rubric: [`project/review-rubric.md`](project/review-rubric.md).
3. **Sponsor verification:** the sponsor attests the project happened, the results are real,
   and, where money is claimed, Finance validated it. Form:
   [`project/sponsor-verification-and-finance-validation.md`](project/sponsor-verification-and-finance-validation.md).

Then: the **90-day sustainment check** (reviewer asks the sponsor whether the control plan
held) feeds the published outcomes page and the badge's `sustained` flag. Random re-review of
10% of certified projects annually, per the audit policy.

**Minimally competent candidate (draft for the Angoff panel):** *Can lead a bounded DMAIC
project on a process they touch: write a cause-free charter with a sponsor, map the process
and measure it with an operational definition and a checked measurement system, state
stability before capability, narrow causes with structured tools and verify the survivors
with the right basic test correctly interpreted, pilot a countermeasure with before/after
evidence, and hand over a control plan — with coaching at each tollgate, and without being
expected to design an experiment, run multiple regression, or lead cross-functional change.*

## Exam blueprint (100-item form · 350-item bank)

| Section | Per form | In bank | Objectives |
|---|---|---|---|
| A. Define: selection, scoping, charter, stakeholders, VOC/CTQ, SIPOC | 12 | 42 | G1 |
| B1. Measure: mapping, VSM, lead time, %C&A, PCE, data types | 8 | 28 | G2 |
| B2. Measure: operational definitions, data collection, sampling, MSA | 9 | 32 | G3 |
| B3. Measure: control charts (basic), stability, capability, DPMO, sigma | 8 | 28 | G4 |
| C1. Analyze: graphical analysis, fishbone, C&E matrix, FMEA, hypothesis framework | 12 | 42 | G5 |
| C2. Analyze: t-tests, ANOVA, chi-square, correlation, simple regression, CIs, interpretation | 16 | 56 | G5 |
| D. Improve: solution generation and selection, pilots, poka-yoke, kaizen, flow basics | 15 | 52 | G6 |
| E. Control: control plans, SPC in sustainment, standard work, response plans, closure, financial validation | 12 | 42 | G7 |
| F. Leading the project: tollgates, sponsor, team, resistance basics, ethics of data | 8 | 28 | G8 |

Constraints: ≈ 40% scenario-judgment (S), ≈ 35% exhibit interpretation (X — a rendered output
table or chart description the candidate must read and conclude from), ≈ 25% concept (K);
≥ 50% Apply/Analyze; vertical rule (NEU plus the cohort vertical); balanced key positions; no
two items sharing a scenario on one form.

**Tag format:** `[section · objective · Bloom · vertical · type · pool]`
Objectives: **G1** scope and charter a project, VOC → CTQ · **G2** map and quantify a process
(VSM, lead time, %C&A, PCE) · **G3** plan data collection and run an MSA · **G4** state
stability, then capability · **G5** isolate and verify root causes with graphical tools and
basic hypothesis tests · **G6** select, pilot and implement countermeasures with
mistake-proofing · **G7** control plan, handover, financial validation, closure ·
**G8** run tollgates, manage sponsor and team, handle data ethically.
