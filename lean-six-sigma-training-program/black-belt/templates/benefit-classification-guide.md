# Benefit Classification Guide — Classes, Calculation Basis, Annualization, Double-Counting Register, Finance Sign-off

*Black Belt toolkit · the classification rows are sent to the Finance partner at Tollgate 2
(the basis they will accept), the evidence window is agreed before it closes, and the
sign-off block is signed at closure. Rubric ★ F1 (Finance sign-off) and F2 (cost of the
project), with D2 (the strategic linkage the benefit lands in). Extends the Green Belt rules
in [`../../green-belt/project/sponsor-verification-and-finance-validation.md`](../../green-belt/project/sponsor-verification-and-finance-validation.md);
program economics in [`../modules/m8-leading-change-and-coaching.md`](../modules/m8-leading-change-and-coaching.md) (8.7).*

## Purpose

A Black Belt project claims impact in the organization's own books, and the books have an
owner. This guide is how you and that owner agree, in advance, what will count, how it will
be calculated, and over what window — so that at closure the Finance partner signs a page
they helped write rather than argues with one they are seeing for the first time. ★ F1 is
mandatory: a project that claims money without a named Finance partner's signature is not
certifiable at any score, and a project that claims no money uses the sponsor's executive
equivalent, named, in the same block.

The guide separates five classes because they are different claims with different evidence.
A headline that adds them together ("$240K of benefit") is the most common way an honest
project becomes an unsignable one.

## The five classes

| Class | Counts as | Does not count as | Evidence Finance needs | Money in the headline? |
|---|---|---|---|---|
| **Hard** | A ledger line that moved over the evidence window because of the change — scrap, overtime, rework labor coded to quality, freight, penalties, interest, purchased services | A rate multiplied by a modeled quantity; a cost that "would have" been incurred | The before-and-after ledger extract for the line; the unit cost with its source and date; the volume basis | Yes, measured; annualized only beside the measured figure |
| **Soft** | Capacity released — hours of people or equipment, units of throughput — that the organization has not yet converted to a ledger movement | Money, unless Finance sets the rate and the row is labeled soft | Time measured on the project's own operational definition (timed observation, system timestamps), before and after; the rate Finance applies, if any | In hours or units; money only at Finance's rate, labeled soft, never in the same total as hard |
| **Cost avoidance** | Budgeted or committed spend that will now not occur — a planned hire, an approved capital request, a contracted overtime block, a penalty clause | Spend that was never approved; a risk that did not materialize | The budget line or commitment, dated before the project started; the decision not to spend, dated | Yes, as its own row, never merged with hard |
| **Revenue** | Revenue booked within the evidence window that traces to the change — a capacity-constrained line that shipped more, a service that now sells | Pipeline, forecast, "enabled" revenue; revenue in a line that is not capacity constrained | The booking; the constraint evidence (the line was sold out before) | Yes, measured margin, not gross, at Finance's basis |
| **Mission / clinical / service** | The primary metric itself — minutes to antibiotic, boarding hours, service-level attainment, safety events | Money derived by multiplying the metric by a charge or a value-of-life figure, unless Finance agrees the rate | The metric on its chart with definition, n and window; the sponsor's executive equivalent (the named validator, not the sponsor) signs | No money unless Finance sets and signs the rate; the metric is the benefit |

## The template

### 1 · Header

| | |
|---|---|
| **Project / Black Belt / sponsor** | |
| **Finance partner (name, title; not in the sponsor's line, not the candidate's line manager)** | |
| **Mission-metric validator, where no money is claimed (name, title)** | |
| **Strategic objective the benefit lands in (D2, quoted)** | |
| **Basis agreed with the Finance partner at Tollgate 2 (date)** | which ledger lines, which unit costs, which window, which annualization rule |
| **Evidence window (start, end, why that length)** | agreed before it closes; long enough for the ledger line to post at least twice |

### 2 · Benefit rows (one row per class per line; never summed across classes)

| Row | Class | What moved (ledger line, metric or hours) | Operational definition of the quantity | Baseline (value, window, n) | Evidence window (value, window, n) | Unit cost or rate, source and date | Measured benefit over the window (units and money) | Annualized by Finance (basis, assumption labeled) | Evidence attached |
|---|---|---|---|---|---|---|---|---|---|
| 1 | Hard | | | | | | | | |
| 2 | Soft | | | | | | | | |
| 3 | Cost avoidance | | | | | | | | |
| 4 | Revenue | | | | | | | | |
| 5 | Mission / clinical / service | | | | | | | | |

### 3 · Calculation basis (one paragraph per row, written so the Finance partner can recompute it)

For each row: the quantity (from the project's chart, same operational definition as baseline),
the unit cost or rate (whose figure, dated), the arithmetic, and what is *not* included. The
sentence "Finance can open every cell" is the test: every number points to a ledger extract, a
costing-system figure, or a timed observation the partner can open.

### 4 · Annualization rules

| Rule | Why |
|---|---|
| The annualized figure is computed by the Finance partner, not the candidate, and appears only beside the measured figure it is derived from | A projection presented alone reads as a result |
| The basis is stated: window × (52 ÷ weeks), or volume plan × unit saving, or the budget line — and the assumption is labeled (volume flat, seasonality, mix) | So a reader can disagree with the assumption, not the arithmetic |
| A seasonal process is not annualized from one season's window | One quarter of a four-season process is a story about that quarter |
| No extrapolation past the evidence window without a labeled assumption; roll-out to units not yet changed is a *projection*, labeled, never a benefit | F2 scores exactly this |
| First-year net = annualized benefit − project cost (section 6); later years stated separately if the benefit continues | The project cost is real money the organization spent |

### 5 · Double-counting register

| Other project or initiative (name, lead, level) | Ledger line, metric or hours it claims | Overlap with this project | How the split was agreed (who, date, initials) |
|---|---|---|---|
| | | | |

Every project, kaizen event and Yellow Belt mini-project touching the same ledger line,
metric or headcount in the same period goes on the register, including the ones with no
overlap — "no overlap" is a finding the reviewer wants to see was checked. The Finance
partner keeps the master register across projects.

### 6 · Cost of the project (F2)

| Cost | Basis | Amount |
|---|---|---|
| Candidate's hours × loaded rate | Finance's rule on whether salaried project time is netted; state it | |
| Team time contracts (from the charter) × loaded rate | hours actually logged, not contracted | |
| Trials and experiments (production time, materials, simulator time) | | |
| Capital and expense (sensors, fixtures, software, training) | including roll-out spend the readout requested | |
| External services | | |
| **Total, and first-year net** | | |

### 7 · Finance sign-off block (★ F1)

| | |
|---|---|
| **Classes claimed and measured figures, one per row (no total across classes)** | Hard $___ · Soft ___ h ($___ at Finance's rate, soft) · Cost avoidance $___ · Revenue $___ · Mission metric: ___ |
| **Annualized figures, computed by Finance, assumptions labeled** | |
| **Project cost and first-year net** | |
| **Double-counting declaration** | *"I have checked this project's rows against the register and against every project on the same ledger lines in the same period; the splits above are agreed."* |
| **Evidence I opened** | ledger extracts (dates), costing figures (dates), timed observations (dates), the chart |
| **Finance partner** — *I accept the basis, I have recomputed the measured figures from the evidence, and the annualized figures are mine.* | name, title, signature, date |
| **Mission-metric validator** (where no money is claimed) — *The metric moved as shown, on the same definition as the baseline, over the window stated, and the sponsor did not validate their own project.* | name, title, signature, date |
| **Sponsor** — *The linkage to the objective quoted above holds.* | name, title, signature, date |
| **Black Belt** | name, signature, date |

### 8 · The partnership schedule

| When | What the Finance partner does |
|---|---|
| Charter (week 2) | Named; confirms they are outside the sponsor's line; sees the impact arithmetic |
| Tollgate 2 (week 5) | Sees the primary metric and its baseline; states in writing the classes, ledger lines, unit costs and window they will accept |
| Before the evidence window closes | Confirms the window and that the ledger line has posted; flags any other project on the same line |
| Closure | Recomputes, annualizes, signs the block |

## Filled example — MFG: scrap at the injection-molding cell

The project from [`../project/charter-and-strategic-linkage.md`](../project/charter-and-strategic-linkage.md)
(section 2.1), at closure. Figures are illustrative and derived as a plant cost accountant
would derive them.

**Header.** Finance partner: plant cost accountant (reports to the plant controller; the
sponsor is the plant manager). Objective: "Cost of poor quality ≤ 2.5% of cost of sales by
FY-end (current 3.9%)." Basis agreed at Tollgate 2 (week 5): hard benefit = scrap-line
movement at the cell, quantity from the weigh-station scrap rate on the charter's definition,
unit cost $0.71 per part (resin + conversion at standard, costing system, Q2); the resin
variance line is *not* claimed separately because at standard cost it is the same money;
start-up purge excluded (it is a different ledger code and a Yellow Belt project); setter
time as soft in hours at the plant's loaded rate of $48/h; annualization on the plan volume
of 4.2 million parts, volume assumed flat. Evidence window: 10 weeks after the roll-out to all
three presses (handover + 5 days to handover + 75 days), long enough for the scrap line to
post in two month-ends.

**Benefit rows.**

| Row | Class | What moved | Definition | Baseline | Evidence window | Unit cost / rate | Measured over the window | Annualized by Finance | Evidence |
|---|---|---|---|---|---|---|---|---|---|
| 1 | Hard | Scrap line, molding cell (cost center 4410, account 5210) | Parts scrapped ÷ parts molded, per production day, three presses, weigh-station count by standard weight; purge excluded | 5.4% (26 weeks, n ≈ 2.1 M parts) | 2.6% (10 weeks, n = 807,000 parts, p chart stable in the post-change stage) | $0.71 per part, standard cost, costing system 14 Apr | (5.4% − 2.6%) × 807,000 = 22,600 parts × $0.71 = **$16,000**; the ledger line fell from an average $13,400 to $6,500 per month over the two month-ends in the window | 4.2 M × 2.8% × $0.71 = **$83,500 per year**, plan volume, flat — computed by the cost accountant | Ledger extract 5210/4410 Jan–Nov; weigh-station log; costing screen |
| 2 | Soft | Setter time at start-up (purge-and-adjust cycle shortened because the setup sheet now lands parts in the window on the first adjustment) | Minutes from first shot to first in-window part, timed by the quality technician, 10 start-ups per shift before and after | 26 min median (10 start-ups, week 4) | 8 min median (10 start-ups, week 22) | $48/h loaded, Finance's rate | 0.3 h × 2 shifts × 48 days = **29 h** over the window (≈ $1,400 at Finance's rate, soft) | 0.3 h × 2 × 250 days = **150 h per year** (≈ $7,200 soft) | Timing sheets; the standard-work document |
| 3 | Cost avoidance | Q4 Saturday scrap-sort overtime block, budgeted $6,000 (budget line 4410-OT-Q4, approved in the Q2 budget) | The block was cancelled by the production manager on 3 Oct because the sort is no longer needed | $6,000 budgeted | $0 spent | — | **$6,000** (one-time; not annualized — it was a one-quarter budget line) | none — a one-time avoidance | Budget approval (May); cancellation email (3 Oct) |
| 4 | Revenue | none claimed | the cell is not capacity constrained; parts not scrapped replace parts that were re-molded, they do not ship more | — | — | — | — | — | — |
| 5 | Mission | none — the plant's objective is financial | — | — | — | — | — | — | — |

**Calculation basis, row 1, as written for the cost accountant.** Quantity: the p chart of
daily scrap rate (all three presses), 26-week baseline stage center 5.4%, post-change stage
center 2.6% from 10 weeks with no rule violation; parts molded from the press counters,
807,000 in the window. Parts not scrapped = 2.8% × 807,000 = 22,600. Unit cost $0.71
(resin $0.44 + conversion $0.27 at standard). Not included: the resin variance line (same
money), purge (Yellow Belt project, different account), the changeover project's press-hours
(different line). The ledger line's own movement ($6,900 per month) agrees with the
computed figure within the mix of standard weights.

**Double-counting register.**

| Other project | Claims | Overlap | Split agreed |
|---|---|---|---|
| Changeover reduction, molding cell (Black Belt, same cohort) | Press hours (line 4410, account 6120 — machine time) | None: it claims hours, this project claims scrap | Both leads and the cost accountant initialed the charter split (week 2) |
| Start-up purge reduction (Yellow Belt mini-project, day-shift setter — the person this candidate coaches, L3) | Resin on the materials line, coded to start-up loss (account 5215), $4,100 per year claimed | None on the ledger: purge is excluded from this project's scrap definition and posts to a different account; the cost accountant confirmed the coding on 7 Oct | Confirmed; the Yellow Belt's row stays with the Yellow Belt |
| Resin variance line (account 5310) | not a project — a ledger line that moves with scrap | The same money as row 1 at standard cost | Claimed once, on 5210; the accountant's note is attached |

**Cost of the project (F2).** Candidate: 320 h × $62 loaded = $19,840 (the plant nets salaried
project time; stated). Team time contracts logged: 118 h × $48 = $5,660. Experiment: press 2
time 13.5 h × $140 = $1,890; resin 60 kg × $3.10 = $190; confirmation runs 3 × 20 min,
negligible. Hold-pressure sensor and setup-sheet build on press 2: $2,300; sensors for presses
1 and 3 (the readout's decision): $4,600. Total **$34,480**. First-year net: $83,500 −
$34,480 = **$49,000**; later years $83,500 gross while the control plan holds. The charter
threshold (≥ $75K annualized target impact) is met on the annualized gross; F2 is met by
stating the net.

**Sign-off block.** Hard $16,000 measured over 10 weeks (annualized $83,500 by the cost
accountant, plan volume flat); soft 29 h measured (150 h per year, $7,200 at Finance's rate,
soft); cost avoidance $6,000 one-time; revenue none; mission none. Project cost $34,480;
first-year net $49,000. Double-counting declaration signed against the register above.
Evidence opened: ledger 5210/4410 extracts (dated), costing screen, timing sheets, the p chart
with its data source. Signed: plant cost accountant; plant manager (sponsor); Black Belt.

*The sentence to the sponsor:* "Scrap at the cell has run at 2.6% for ten weeks against 5.4%
before, on the same weigh-station definition — about 22,600 parts and $16,000 of scrap in
the window, which the cost accountant annualizes to about $83,500 a year at plan volume. The
project cost about $34,500 including the sensors for the other two presses, so the first
year nets about $49,000. Setter time at start-up is down about 18 minutes a shift; that is
capacity, not cash, and it is on the page in hours."

## Common mistakes

- **One headline number.** Five classes, five rows, never summed. A reviewer who sees
  "$96,500 of benefit" made of hard, soft-at-a-rate and avoidance scores F1 as unearned
  until the rows are separated.
- **Soft hours presented as hard money.** Hours released are a benefit in hours. They become
  money when a ledger line moves — a position not backfilled, overtime not paid — and then
  they are a hard row with that evidence.
- **Annualized figure with no measured figure beside it.** The projection reads as the result.
  Measured first, annualized by Finance beside it, assumption labeled.
- **The Finance partner met at closure.** The basis is stated at Tollgate 2. A basis argued at
  closure is a month's delay and often a smaller number.
- **The Finance partner in the sponsor's line, or the candidate's manager.** Independence is
  the point of the signature.
- **Claiming the same money twice through two ledger lines.** Scrap at standard cost and the
  resin variance; rework hours and the overtime line they post to. The register catches it
  only if you write the lines down.
- **Revenue from a line that is not constrained.** Fewer defects on a line with spare capacity
  produce fewer defects, not more sales.
- **Money on a mission metric.** Boarding hours × a bed-day charge, minutes to antibiotic × a
  cost of sepsis — numbers Finance cannot sign. The metric is the benefit; the validator is
  the sponsor's executive equivalent, named.
- **Project cost omitted or the candidate's time netted by a rule Finance did not set.** State
  Finance's rule and apply it.
- **Extrapolating roll-out.** Presses 1 and 3 not yet changed are a projection, labeled, in the
  annualization note — never a measured row.
