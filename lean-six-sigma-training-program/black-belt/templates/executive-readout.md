# Executive Readout — The One-Page Standard, ≤ 15 Minutes, Decisions Requested, the Honest-Results Rule

*Black Belt toolkit · rehearsed in Immersion 2 (week 15), delivered to the sponsor's peers
when a decision is needed (roll-out, funding, a scorecard adjustment) and again at closure.
Rubric L2: "executive readout delivered (recorded or observed) in ≤ 15 minutes, one page,
decisions requested and obtained"; S1 for the record; the chart is the ★ I1 exhibit and the
money line is the ★ F1 basis. Method: [`../modules/m8-leading-change-and-coaching.md`](../modules/m8-leading-change-and-coaching.md)
(8.5). The cost rows the decisions are built from come from the
[`stakeholder-strategy-canvas.md`](stakeholder-strategy-canvas.md).*

## Purpose

An executive readout exists to obtain a decision. It is one page, because the executives will
read it from the top down and one of them will leave at minute ten; it is fifteen minutes,
because the decision takes the rest of the meeting; and its order is fixed, because the
decision is asked for first, supported second, and asked for again at the end with the date
it is needed by and what waiting costs.

The page is also where the program's data ethics become visible to people who will never see
the analysis file. One chart, unbroken from the baseline through the change to now, with the
prediction drawn on it, the definition, n and window written on it, and the line that says
what did not work. A readout that shows a window starting after a bad month, an annualized
figure with no measured figure beside it, or a prediction that appeared after the result is
a readout the reviewer scores as L2 unearned and, where the data were reshaped, as the
data-ethics stop.

## The one-page standard

The page has six blocks in this order and nothing else. Everything the executives might ask
for is in the appendix you bring and do not present.

### Block 1 · The decision you need (one sentence, first)

| | |
|---|---|
| **"I need ___ decision(s) today: …"** | each in one clause; the owner of each decision named by role |

### Block 2 · The gap in their metric

| | |
|---|---|
| **The objective, quoted** (D2) | the organization's own words, with its source |
| **Where it was · where it is** | the primary metric's baseline and current value, same definition, windows and n stated |
| **What this project's share of the gap is** | the arithmetic line from the charter, one sentence |

### Block 3 · What we found

| | |
|---|---|
| **The verified cause, in plain language, with its effect size** | the sentence from Module 4 or Module 5 — an effect in the process's units at named settings; never a p-value alone |
| **How it was verified** (method in three words) | "a designed experiment on press 2"; "a regression on 261 patients with diagnostics" |

### Block 4 · What we changed and what happened (the chart)

| | |
|---|---|
| **The change, one line** | |
| **The chart** | one chart, continuous from the baseline stage through the change to today; the change date marked; the prediction drawn as a reference line; definition, n, window and data source printed on it; y-axis from zero or the reason stated; no dual axes |
| **Result against prediction** | "predicted ___; observed ___ over ___ (n = ___)" — including when the prediction was not met |
| **Guardrails** | each, one number |
| **Money or mission metric, in the class Finance agreed** | measured over the window; an annualized figure only beside it, labeled "annualized by [Finance partner]"; no total across classes |

### Block 5 · What did not work (one line)

| | |
|---|---|
| **The countermeasure, hypothesis or period that did not deliver, and what it taught** | it is on the chart; it buys the credibility of everything above it |

### Block 6 · The decisions again, with dates and the cost of waiting

| # | Decision requested | Owner (role) | Needed by | What waiting costs (in their units) | Obtained? (yes / no / deferred to when) — recorded after the meeting |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |

### Timing (15 minutes)

| Block | Minutes | Note |
|---|---|---|
| 1 The decision | 1 | Read the sentence; do not explain it yet |
| 2 The gap | 2 | Their metric, their words |
| 3 What we found | 3 | The effect in units; stop |
| 4 The chart | 4 | Walk the chart left to right, prediction, result, guardrail, money line |
| 5 What did not work | 1 | One line, on the chart |
| 6 The decisions | 4 | Each decision, its owner, its date, what waiting costs; then silence |

The page is sent 48 hours before as a pre-read; the appendix (canvas, diagnostics, the
benefit rows, the control plan) is available and not presented.

### The honest-results rule (checked before the page leaves your hands)

| Check | Yes / no |
|---|---|
| The chart starts at the baseline the charter used, not after a bad month, and the operational definition is the same throughout | |
| The prediction on the chart was dated before the pilot or experiment started (the pilot plan or the canvas is the evidence) | |
| An unmet or partly met prediction is stated as such in block 4 | |
| n, window and data source are printed on the chart; the y-axis starts at zero or the page says why not | |
| No average of averages, no percentage of a percentage, no "60% improvement" from a two-day window | |
| Money is in the class Finance agreed, measured first, annualized only beside the measured figure with the partner named; no total across classes | |
| Mission metrics carry no money unless Finance set the rate | |
| Block 5 names something that did not work; if nothing did not work, the page says what was expected and not seen | |
| The guardrails are on the page with numbers | |
| Nobody on the page is blamed; every failure traces to a design decision | |

### The record (L2 evidence, kept with the page)

| | |
|---|---|
| **Date, audience (roles), duration** | from the recording or the observer's note |
| **Decisions obtained, deferred or refused** (block 6, completed) | |
| **Observer or recording reference** | |
| **The sponsor's or observer's one line on the readout** | |

## Filled example — MFG: scrap at the injection-molding cell, week 16 readout

The project from [`../project/charter-and-strategic-linkage.md`](../project/charter-and-strategic-linkage.md)
(section 2.1), delivered to the plant manager (sponsor), the production manager, the
maintenance manager and the plant controller, 14 minutes, recorded. Numbers are illustrative
and consistent with the experiment in [`doe-planning-canvas.md`](doe-planning-canvas.md).

**Block 1.** *"I need three decisions today: approve the revised setup sheet as the standard
on presses 1 and 3 from next Monday; release the two setters for two hours a week for four
more weeks to train presses 1 and 3; and hold the press-utilization line on the cell scorecard
at plan for those four weeks while the confirmation runs are made."*

**Block 2.** Objective, quoted: "Cost of poor quality ≤ 2.5% of cost of sales by FY-end
(current 3.9%)" — plant scorecard, Q2 review. Scrap at the cell was 5.4% of parts molded over
26 weeks (n ≈ 2.1 million parts, weigh-station count); on press 2 it has been 2.4% for the
last 19 production days (n = 106,000 parts, same definition). The cell's scrap is about one
sixth of the CoPQ gap; presses 1 and 3 are two thirds of the cell's volume and are still at
baseline.

**Block 3.** "Short shots on tool 4471 are a hold-pressure problem, not a temperature
problem. Raising hold pressure from 60 to 72 bar with a 6-second hold adds about 0.9 g of
part weight — from 41.3 to 42.2 g against a 41.2 g short-shot limit — and the two settings
have to be set together: at 4 seconds of hold, pressure alone does half as much. Melt
temperature, which the setup sheet has always adjusted first, made no difference above a
quarter of a gram." Verified by a designed experiment on press 2 (20 runs, two shifts) and
three confirmation runs at the chosen settings.

**Block 4.** Change: setup sheet SS-4471 v2 on press 2 from day 0 (week 12); hold pressure
and hold time specified jointly with a window; a hold-pressure sensor added so the setting
is displayed, not inferred. The chart: p chart of daily scrap rate on press 2, 26-week
baseline stage (center 5.4%), change date marked, prediction 2.5% drawn as a dashed
reference (written on the canvas in week 8), 28 days after the change; definition, n per day
(≈ 5,600 parts) and the weigh-station source printed on it; y-axis 0–10%. Result against
prediction: predicted 2.5%; observed 2.4% over the last 19 days (n = 106,000 parts) — and
5.1% over the first 9 days, below. Guardrails: cycle time 38.9 s against 38.4 s at baseline
(+1.3%, inside the 5% trigger); first-pass dimensional yield 99.1% against 98.9%. Money: hard,
measured on press 2 over 19 days — 3,190 parts not scrapped × $0.71 = $2,270 at standard
cost (the plant cost accountant's basis); if the result holds across the three presses, the
cost accountant annualizes it to about $83,500 a year at plan volume — a projection, labeled,
which is what the first decision is for.

**Block 5.** "For nine days after the change, scrap on press 2 stayed at 5.1%. The first
version of the setup sheet listed hold pressure in psi because the tool card is in psi, and
the press controller reads bar; the setters set 72 and got 72 bar's worth of psi — about
5 bar. The sheet now carries both units and the sensor displays bar. It is on the chart."

**Block 6.**

| # | Decision | Owner | Needed by | What waiting costs | Obtained? |
|---|---|---|---|---|---|
| 1 | Setup sheet SS-4471 v2 as the standard on presses 1 and 3 | Production manager | Monday (5 working days) | ≈ 630 parts scrapped per day on the two presses at baseline ≈ $450 a day at standard | Yes, at the meeting |
| 2 | Two setters released 2 h/week × 4 weeks to train and run confirmation on presses 1 and 3 | Production manager, with the cell supervisor | Monday | Roll-out without the setters is a sheet on a wall; the psi/bar error was caught by a setter | Yes |
| 3 | Press-utilization line held at plan for 4 weeks (three confirmation runs per press ≈ 2 h each) | Plant manager | Before the month-end scorecard | Without it the cell supervisor's number worsens for the roll-out she is being asked to run | Deferred two days; obtained in writing on the Wednesday |

**The record.** Week 16, Thursday; plant manager, production manager, maintenance manager,
plant controller; 14 minutes on the recording; three decisions requested, two obtained at the
meeting, one obtained within two days; unmet stretch of the prediction (the first nine days)
shown. The plant manager's line to the observer: *"He told us the nine bad days before we
found them on the chart."*

## Common mistakes

- **Opening with the fishbone.** The first sentence is the decision. The method goes in block
  3 in three words; the analysis is in the appendix.
- **A chart window that starts at the pilot.** The chart starts at the baseline the charter
  used. A window that begins after a bad month is a reconstructed baseline and the data-ethics
  stop.
- **No prediction on the chart.** The prediction, dated before the change, is what makes the
  result a result. An unmet prediction stated plainly is credibility; one hidden is L2 lost.
- **The annualized headline.** $83,500 a year on a page with no measured figure beside it is a
  projection dressed as a result. Measured first, annualized beside it, the Finance partner
  named, the roll-out assumption labeled.
- **Money on a mission metric.** Boarding hours or minutes to antibiotic multiplied by a rate
  Finance did not set. The metric is the result.
- **Nothing that did not work.** Every project has one. A page without block 5 reads as a page
  with something missing.
- **Decisions without owners, dates or the cost of waiting.** "We recommend roll-out" is not a
  decision request. Name the role, the date, and what each week of delay costs in their units.
- **Fifteen slides for fifteen minutes.** One page. If a second page is needed, it is the
  appendix and it is not presented.
- **Blame on the page.** The psi/bar error is a design failure of the setup sheet, not a
  setter's mistake, and the page says so.
- **No record.** L2 is "decisions requested and obtained". Complete block 6 after the meeting,
  with dates, and file it with the recording or the observer's note.

## Rubric items evidenced

| Item | What on this page evidences it |
|---|---|
| L2 Executive communication | One page, ≤ 15 minutes (recorded or observed), decisions requested in block 1 and obtained in block 6 with dates |
| ★ I1 Experimental or piloted solution evidence | Block 4: the chart continuous from baseline with the dated prediction, the result compared to it, and the honest reading of the first nine days |
| ★ A2 Root cause verified | Block 3: the effect in the process's units at named settings, the method named |
| ★ F1 / F2 Finance | Block 4's money line in the class Finance agreed, measured first, annualized beside it by the named partner, roll-out labeled as a projection |
| D2 Strategic linkage | Block 2: the objective quoted, the share of the gap stated |
| S1 The record | The chart labeled with source, n, window and definition; a stranger can follow the page |
| ★ L1 (supporting) | Block 6's third decision is a stakeholder move from the canvas — the cell supervisor's scorecard protected before she is asked to act |
