# Yellow Belt — Contributing to Improvement Projects

**Format:** Hybrid-lite — self-paced e-learning + 2 live virtual workshops
**Duration:** ~12–14 hours over 2–4 weeks (8–10 hrs self-paced, 2×90-min workshops, plus
mini-project time in the learner's own work)
**Prerequisites:** White Belt certificate, or the 1-hour bridge module (fee-waived)
**Credential:** Certified Lean Six Sigma Yellow Belt — exam **and** rubric-reviewed real
mini-project required. 1.2 IACET CEUs (pending accreditation).

## Course structure

| Component | Content | Time |
|---|---|---|
| **Unit 1** | Process Thinking: SIPOC & Process Mapping | 2.0 h self-paced |
| **Workshop 1** | Process Mapping Clinic (live, virtual) | 1.5 h live |
| **Unit 2** | Workplace Organization: 5S, Visual Management & Standard Work | 1.5 h self-paced |
| **Unit 3** | Data Basics: Check Sheets, Pareto & Run Charts | 2.0 h self-paced |
| **Unit 4** | Root Cause: Problem Statements, 5 Whys & Fishbone | 1.5 h self-paced |
| **Workshop 2** | Root-Cause Simulation (live, virtual) | 1.5 h live |
| **Unit 5** | Improvement in Action: PDCA, Just-Do-It & Your Role on DMAIC Teams | 1.5 h self-paced |
| **Simulation** | One full improvement cycle in the virtual sim (pizza-order / catapult) | ~1 h embedded |
| **Exam** | 40 questions, 75% pass, 2 retakes included | 1 h |
| **Mini-project** | Real Just-Do-It improvement, A3-lite storyboard, instructor-reviewed | learner's workplace |

Recommended sequence: Unit 1 → Workshop 1 → Units 2–4 → Workshop 2 → Unit 5 → exam →
mini-project submission (may trail by up to 60 days; certification issues when both gates pass).

Individual enrollees join the monthly public workshop sessions; corporate cohorts get private
sessions (or the 2-day on-site bootcamp variant that compresses all units and workshops).

## Certification gates
1. **Exam:** 40 questions (≥50% scenario-based), **75% pass**, two retakes included with fresh
   forms. Item bank: [`exam-bank.md`](exam-bank.md).
2. **Mini-project:** a real improvement in the learner's own work area, documented on the
   A3-lite storyboard and scored by a certified instructor against the published rubric —
   **pass = 7/10 with no dimension scored zero.**
   Template: [`mini-project/storyboard-template.md`](mini-project/storyboard-template.md) ·
   Rubric: [`mini-project/rubric.md`](mini-project/rubric.md).

## Design notes for content/production team
- Units are written as teach-text; storyboard each into 15–20-min interactive segments with
  the same Hook → Teach → Show → Try pattern as White Belt.
- All examples ship in three vertical flavors (manufacturing / healthcare / transactional);
  the units below carry the skeleton with examples from each.
- The virtual simulation (one full improvement cycle with real collected data) is embedded
  across Units 3–5: learners collect check-sheet data in the sim (Unit 3), analyze causes
  (Unit 4), and run a PDCA countermeasure (Unit 5).
