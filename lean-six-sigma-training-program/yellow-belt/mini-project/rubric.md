# Yellow Belt Mini-Project — Scoring Rubric

**Pass = 7/10 with no dimension scored 0.** Scored by a certified instructor; feedback
within 10 business days; one revise-and-resubmit cycle included in tuition. This rubric is
published to learners on day one — the storyboard is written *toward* it, not surprised
by it.

Each dimension: **0** (absent/fatal), **1** (present but weak), **2** (solid).

---

## 1. Real problem, honestly stated
| Score | Looks like |
|---|---|
| **0** | No real workplace problem (hypothetical, someone else's process, or a solution wearing a problem costume); or statement contains blame |
| **1** | Real problem, but statement is vague/unquantified, or smuggles a cause or solution ("lack of…") |
| **2** | Real problem in the learner's own work; statement gives what/where/when/how big/why it matters, cause-free and blame-free |

## 2. Baseline before the change
| Score | Looks like |
|---|---|
| **0** | No baseline, or "baseline" reconstructed from memory after the change |
| **1** | Baseline exists but thin (single point, unclear operational definition, or collection method not stated) |
| **2** | Baseline collected before the change with a stated operational definition and method: a run of data, a tally over a defined period, or a scored 5S audit + photos |

## 3. Action taken on a verified cause *(for 5S: disciplined execution)*
| Score | Looks like |
|---|---|
| **0** | No change actually implemented, or countermeasure aimed at an unexamined guess with no cause work shown |
| **1** | Change implemented; cause chain present but stops early (at a person, or at an unchecked theory), or 5S executed partially (Sort/Set only, no standard) |
| **2** | Cause drilled to an actionable process cause with a stated verification (watched/counted/tested), and the countermeasure targets it; or 5S executed through Standardize with the red-tag discipline evidenced |

## 4. Result measured against the baseline **(mandatory-strength dimension — see pass rule)**
| Score | Looks like |
|---|---|
| **0** | No after-measurement, or metric/definition switched between before and after |
| **1** | After-measurement exists but weak (very short window, or prediction absent so "success" is unfalsifiable) |
| **2** | Same metric, same definition, same method, before vs. after; result compared to a written prediction; honest reading of Partial/Not-met outcomes. (A well-documented "didn't work, here's what I learned and would try next" **can score 2** — honesty is the standard, not victory) |

## 5. Storyboard clarity & sustainment
| Score | Looks like |
|---|---|
| **0** | Unreadable/off-template, or no sustainment mechanism at all |
| **1** | Follows the A3-lite flow but bloated or evidence-thin; sustainment gestured at ("we'll keep an eye on it") |
| **2** | One page, exhibits over prose, a stranger could follow problem → cause → change → result; sustainment is named and owned (updated standard, visual control, scheduled audit with a name on it) |

---

## Reviewer guidance
- **The "no zeros" rule does the heavy lifting.** A charming storyboard with no baseline
  fails. An ugly one with honest before/after data passes. That asymmetry is the program's
  credibility, applied at its smallest scale — protect it.
- **Honest failure passes; cosmetic success doesn't.** If every submission reports triumph,
  we are grading fiction. Praise and pass well-documented partial/failed Checks (D4=2 is
  explicitly available to them); flag suspiciously perfect results for a friendly follow-up
  question, not an accusation.
- **Scope rescue, not scope punishment:** an over-scoped project ("fix the ERP") that
  honestly documents one completed slice can still pass on that slice; coach the rest
  toward escalation (and note the Green Belt lead per the progression pathway).
- **Feedback format:** two strengths, the score per dimension with one sentence each, and —
  for any resubmission — the *single* highest-leverage fix first. Resubmissions are
  re-scored on the same rubric by the same reviewer.
- **Calibration:** all reviewers score the shared sample set quarterly (three storyboards:
  a clean pass, a no-baseline fail, an honest-failure pass); drift >1 point on any
  dimension triggers re-calibration before further live scoring. Random 10% of passed
  storyboards re-reviewed annually per the program audit policy.
