# Program Change Log

Every substantive change to curriculum, assessment, or certification requirements. Required by
the authoring style guide §8. Assessment and requirement changes carry a rationale and an
effective date and are never applied retroactively to enrolled candidates.

Change classes: **CUR** curriculum/content · **ASM** assessment (items, blueprints, cut scores)
· **CRT** certification requirements or credential definition · **OPS** operations/policy ·
**PRD** production/delivery specification.
