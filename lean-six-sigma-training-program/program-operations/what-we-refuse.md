# What This Program Refuses To Do

*Published, because a refusal is a promise you can hold us to.*

Each line below is a decision already made in the program's design documents, with the
place it lives. If we ever break one, the change log will show it and the improvement board
will carry the reason.

| We will not… | Because | Where the decision lives |
|---|---|---|
| **Certify anyone without applied work** — at any level, including White Belt | A credential that can be earned by watching is a receipt, not a credential | White Belt credential spec §2.1; Yellow Belt gates; program blueprint |
| **Run an exam with a pass rate we would be embarrassed to publish** — and we publish it | A pass rate above 95% means the exam is decorative | Evaluation plan; outcomes page |
| **Let the instructor who coached a project certify it** (Green Belt and above) | Grade-your-own-homework is how credentials rot | Program blueprint, pitfalls table |
| **Auto-grade the thing that matters** | Formative feedback can be automated; the certification verdict is a human's, calibrated and named | Field-exercise rubric; coach specification |
| **Sell an "advanced White Belt," a "Yellow Belt Plus," or any tier between belts** | Belt inflation is how these businesses die | Reinforcement kit §6 |
| **Charge an awareness-credential holder to renew** | Revenue extracted against our own integrity claims | Credential spec §2.3 (`expires: none`); reinforcement kit §6 |
| **Claim CEUs at White Belt** | It does not meet the criteria; claiming it would risk the accreditation we pursue for Yellow and above | Credential spec §2.6 |
| **Launch a corporate rollout with no named response owner** | Awareness rollouts fail as suggestion boxes, not as courses | Rollout playbook, readiness gate |
| **Let an observation be used in a performance review** | One such case ends the program's credibility overnight | Rollout playbook §8; manager brief |
| **Report a learner's reflections, dossier or item-level answers to their employer** | Data honesty taught in Module 3 is worthless if the course surveils the learner | Production spec §4.3; terms of certification §7 |
| **Quote a benchmark we have not measured** | Secondhand numbers are what every other course has | Benchmark library |
| **Publish an impact figure without its n, period and label** | Overclaiming at awareness level destroys CFO credibility at Green | Outcomes page §2; evaluation plan L4 |
| **Use drag-and-drop, or ship a module that fails the accessibility gate** | Pointer gestures exclude people; "we'll fix it later" never comes | Production spec, WCAG 2.2 AA gate |
| **Name a person as a cause, anywhere in our content** | The module that teaches "blame the process" cannot do otherwise | Authoring style guide; role and vertical variant rules |
| **Compete on being cheapest or fastest to a certificate** | Those are the mills' axes; racing to hand out certificates is the mill trap | Program blueprint, market differentiation |
| **Hide a problem someone reported about the course** | Every report is on the improvement board with a status; silence is the one status we do not allow | Improvement board |

If you think we have broken one of these, pull the cord in any module or write to the
assessment lead. The report goes on the board.
